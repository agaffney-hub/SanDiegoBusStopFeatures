Transit Accessibility in San Diego County

This project evaluates public transit stop accessibility by analyzing infrastructure features, environmental barriers, and accessibility conditions using GIS and street-level imagery.

Accessibility Scoring

Categories and variables:

  • Physical access - can someone physically reach the stop
    • Distance to sidewalk
    • Sidewalk nearby
    • ADA curb ramp nearby
    • Crosswalk nearby
  • Boarding access - can someone board the public transportation
    • Wheelchair boarding
    • Number of routes
    • Service frequency
    • Stop signage
  • Passenger comfort - can someone wait comfortably for public transportation
    • Shelter
    • Bench
    • Tree canopy
  • Connectivity - can a rider continue their ride to somewhere else
    • Bike lane nearby
    • Bike rack nearby

Steps to Calculate:

  1. For each variable in each category, give a score.
    • Scoring:
      • Binary variables - 0 = No, 1 = Yes
      • Continuous variables - normalized using min-max normalization
      • Normalized Value = (x - min(x)) / (max(x) - min(x))


  2. Add up the scores for each variable and divide by the number of variables in the category.


  3. Multiply each category by its weight (0.40, 0.25, etc.) to get the weighted accessibility index.
    • Weights:
      • (35%) Physical access
      • (30%) Boarding access
      • (20%) Passenger comfort
      • (15%) Connectivity
    • Weighting helps to indicate that a stop with a bench is still usable, but a stop without a sidewalk might not be.


  4. Calculate accessibility score by using accessibility score = 1 + (weighted index * 9). This means that if the index is 0, the accessibility score would be 1; if the index is 1, then the accessibility score would be 10.
    • Using this formula prevents having an accessibility score of 0, which could be difficult for users to interpret.
