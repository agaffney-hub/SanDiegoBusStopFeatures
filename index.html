Transit Accessibility in San Diego County

This project evaluates public transit stop accessibility by analyzing infrastructure features, environmental barriers, and accessibility conditions using GIS and street-level imagery.

About Data Sources Research Methods Team SDG Connections

About the Project

Many people rely on public transportation for daily mobility, but barriers at transit stops can prevent equitable access. This project examines stop features across San Diego County to identify opportunities for improving accessibility and creating more inclusive transportation spaces.

Transit Agencies

San Diego Metropolitan Transit System (MTS) and North County Transit District (NCTD)
